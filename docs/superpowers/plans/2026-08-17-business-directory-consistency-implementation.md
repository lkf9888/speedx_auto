> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish one consistent SPEEDX AUTO identity across the website, Google Business Profile, BBB, Yelp, and YellowPages, with Monday-Saturday 10:00 AM-6:30 PM hours, the current phone, and the correct postal code.

**Architecture:** Keep the website's canonical facts in the existing shared company and locale modules, with JSON-LD generated by the existing structured-data builder. Treat each third-party profile as an independent external workflow: search for duplicates, claim before creating, submit only canonical facts, and record the exact saved/review/verification/public state in the external entity checklist.

**Tech Stack:** Next.js 16, TypeScript, Vitest, ESLint, Render deployment, Google Business Profile, BBB, Yelp, YellowPages

- Phone: `+1 (778) 917-0710`.
- Address: `2980 Number 3 Rd, Richmond, BC V6X 2B3`.
- Website: `https://speedxrental.com/en`.
- Hours: Monday-Saturday, `10:00 AM-6:30 PM`; Sunday closed.

- Do not create duplicate profiles; claim a matching profile instead.
