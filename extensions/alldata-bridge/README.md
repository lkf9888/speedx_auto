# SPEEDX ALLDATA 助手（Chrome 扩展）

让维修工作台（repair.speedxrental.com）用**这台电脑上已登录的 ALLDATA** 做三件事：

- 把工作台里核对好的估价单草稿建成 ALLDATA 估价单（Estimate）
- 查 ALLDATA 历史单据（估价单 / 工单 / 发票）
- 打开单据 PDF，用 Chrome 自带的 PDF 查看器打印或下载

ALLDATA 有反机器人防护，服务器不能替我们登录，所以这些操作都在员工自己的 Chrome 里完成。扩展不保存、也看不到 ALLDATA 密码；只有员工在工作台点按钮时才会动作。

## 安装（每台电脑一次）

1. 把整个 `alldata-bridge` 文件夹放到电脑上一个固定位置（例如“文稿/SPEEDX/alldata-bridge”），之后不要移动或删除。
2. Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点“加载已解压的扩展程序”，选择这个 `alldata-bridge` 文件夹。
5. 在同一个 Chrome 里打开 https://my.alldata.com 并登录 ALLDATA（之后保持登录即可）。
6. 打开（或刷新）维修工作台。

## 使用

- 在对话里报价确定后说“开 ALLDATA 估价单”（可以带上客户姓名电话、里程），工作台会生成一张草稿卡片。
- 在卡片里按电话或姓名查找 ALLDATA 客户，选中客户和车辆（或选“不关联客户”），点“在 ALLDATA 创建估价单”。
- 建好后点“打开 PDF（打印 / 下载）”。
- 历史单据和收据：点工作台右上角“ALLDATA 单据”，按姓名 / 电话 / 单号查找，点对应的 PDF 按钮。

建单时技师默认 Jason、服务顾问默认 Kevin（和 ALLDATA 里“Create New Document”一样）；工时都记在 “Basic Labor” 费率下。转工单、开发票、收款仍在 ALLDATA 里操作。

## Westcan（Nexpart）查价（1.1.0 起）

WorldPac 本地仓库没货时，工作台会自动用这台电脑的 Chrome 去 Westcan 的 Nexpart（https://3501660.nexpart.com）查同一个零件：

- 需要在同一个 Chrome 里登录 Nexpart，并**保持一个 Nexpart 标签页开着**（没有开着的，扩展会在后台打开目录页；没登录会提示先登录）。
- 只查价格和库存，不下单、不保存任何东西。扩展会在 Nexpart 里选中这台车（和员工手动选车一样）。
- 报价规则：Westcan 零件按拿货价 × 1.3；顺序是 WorldPac 本地有货 → Westcan（Richmond 有货优先，其次其他分店、明天到）→ WorldPac 调货 → 待补价。
- Nexpart 分不清发动机时，卡片会提示先告诉助手发动机或 VIN。

## 加进购物车（1.2.0 起，Westcan 和 Lordco）

工作台里，来自 Westcan 或 Lordco 的零件旁边有“加进购物车”按钮。点了会先让你确认零件、数量和进价，确认后扩展在**后台打开一个新标签页**（用这台电脑已登录的 Nexpart），在“Stock Check”里输入零件号和数量，按网页自己的“Add to Cart”，看到购物车数量增加就关掉这个标签页，并告诉工作台结果。

- **只加购物车，不下单。** 扩展从不点 Buy Now 或 Place Order；到 Nexpart 的购物车页面核对后，由你自己点 Place Order。
- 需要在同一个 Chrome 里登录对应的 Nexpart：Westcan `3501660.nexpart.com`，Lordco `1000027.nexpart.com`。
- 1.2.0 新增了 Lordco 的网站权限，更新后 Chrome 可能提示“扩展需要新的权限”，请点同意（在 `chrome://extensions` 里如果扩展显示错误，先点刷新）。
- 找不到零件（Nexpart 里没有这个零件号）、没登录、页面改版，工作台都会明说，什么都不会被加进购物车。

## 草稿与回读（1.3.0 起）

工作台的 ALLDATA 草稿卡多了“在 ALLDATA 创建草稿并核对”：

- 只建 ALLDATA 的**草稿（Draft）**：不领单号、不发给客人、不收款；员工要正式报价时再转成估价单。
- 建好后扩展把这张单读回来（不含客户资料），工作台和卡上逐项核对（行、数量、单价、税前合计、GST/PST、含税合计、技师、顾问、备注），哪里不一致会写出来。
- 开草稿前必须先选 PST 收不收（ALLDATA 的 PST 是员工逐单决定，不是自动的）。
- **修了一个旧问题**：ALLDATA 的自定义零件“价格 = 进价 + 加价”，只传单价它会忽略，零件会按进价入账。现在零件的进价放进 Cost，客人价与进价的差额放进 Markup，并在第一次保存后再保存一次让加价生效；不知道进价时，把客人价当 Cost、加价为 0（店里的惯例）。

## 改单、查单、转单据（1.3.0）

对话里说“把 #1062 的前刹车片改成 105”“加一条一口价”“里程改 82000”“换技师”“换客户”“查一下 1062”，助手会在对话里放一张“ALLDATA 改单”卡：

- 卡会读出这张单现在的样子，列出**改前 → 改后**和新的含税合计，员工按“在 ALLDATA 应用修改”才真的保存；保存后再读回来逐项核对。
- 只能改草稿和估价单。发票、已作废的单 ALLDATA 都锁定，卡会直接说不能改。目录零件、套餐、备注行也不改（在 ALLDATA 里改）。
- 需要老板确认（卡上必须勾“老板已确认这次改动”）：合计变动 ≥ $50 或 ≥ 单据金额 10%（取较小者）；已打印或发送过的估价单（读不到打印记录也算）；更换客户。勾选只对眼前这一次改动有效，改动一变就要重勾。
- 转成估价单（领取单号）和转成发票（不可撤销，要输入“开发票”）是卡上单独的按钮；有未完成或没法放置的修改时不显示。
- 保存前扩展会核对：这张单没有被别人改过；ALLDATA 设置里的税开关（GST / PST，PST 是员工在设置里按单开关的）和读取时一样，否则拒绝保存，因为每次保存都按当时的设置重新计税。

## RockAuto 查价（1.4.0 起）

WorldPac、Westcan、Lordco 都没有本地货时，工作台会去 RockAuto 查同一个零件号的价格，作为一个邮寄来的备选（价格 +  每个零件号估 $15 运费，再 × 1.3）。RockAuto 会拦截服务器所在的机房地址，所以服务器读不了时，由**这台电脑的 Chrome** 去读：

- 扩展会在**后台开一个新标签页**（RockAuto 的公开零件搜索页，每个零件号一页，最多 4 个，每页之间停 1.2 秒），读完关掉。
- **只读，不登录，不加购物车，不下单，不碰任何账号。** 只把页面上的零件列表送回工作台，价格换算由工作台的服务器做。
- 要看到加元价：用店里加拿大的网络访问时 RockAuto 默认显示加元；如果页面不是加元，工作台会说“没查成”，不会把美元当加元用。
- 1.4.0 新增了 RockAuto（www.rockauto.com）的网站权限，更新后 Chrome 可能提示“扩展需要新的权限”，请点同意（在 `chrome://extensions` 里如果扩展显示错误，先点刷新）。
- RockAuto 的页面如果出现脚本验证，真实的 Chrome 标签页会自己通过；扩展不会也不应该绕过任何验证。通不过时工作台写“没查成”，员工点“RockAuto 搜索”手动查。

## 出问题时（1.3.0）

扩展对写操作从不自动重试。连接断了、ALLDATA 没回应、返回 5xx，或返回的单据缺了预期字段（可能改版），工作台会停下来，把这次写入当作“结果不确定”：卡上锁住同一个写操作，让员工先到 ALLDATA 里看过再解锁。会话过期就请员工在 Chrome 里登录 ALLDATA（不输入密码、不绕验证码）。每一步都会写进“ALLDATA 单据”窗口里的操作日志（只记次数和金额，不记客户信息）。

## 更新

扩展代码有更新时，把新文件覆盖到同一个文件夹，然后在 `chrome://extensions` 里点这个扩展的刷新按钮。
